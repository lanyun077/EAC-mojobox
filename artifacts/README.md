# 开发者原始产物

在这里放置通过收录流程的 `<id>-<version>.dshpack`，保留开发者原始字节。每个归档必须有 `catalog/feature-packs/<id>.json` 记录，摘要与实际文件相符。

一个稳定 ID 的收录记录指向当前版本；升级后旧归档原始字节可保留作历史对照，不进入当前
目录与网站下载。自制功能包本轮新增七个 `0.1.0`，原七个基底升级到 `0.2.0`。

不放测试样本、凭据或本机 Profile。DSH-EAC 自制薄包的清单与重复打包命令见
[authoring/](../authoring/README.md)，第三方插件仍由上游发布。详见 [收录规范](../docs/intake.md)。
