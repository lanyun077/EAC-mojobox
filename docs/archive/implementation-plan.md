## 历史六阶段计划（不再作为当前执行顺序）

本计划以 [MVP 开发边界与计划](mvp-development.md) 为准，目标是尽快交付一条可用链路：
目录可看、功能整合包可收录、宿主市场可一键安装。

当前阻塞、候选包证据、方案比较和外部模型审查问题见[可行性审查包](mojobox-feasibility-review.md)。

## 当前边界

| 范围 | 决策 |
| --- | --- |
| 目录 | 保留静态网站，展示功能整合包和真实摘要 |
| 安装格式 | 采用宿主 Feature Pack v1：`formatVersion: 1`、`pack.json`、`packs-index.json` |
| 宿主 | 复用官方桌面端已有 Host 插件和 Feature Pack CLI |
| 首个内容 | 用户指定的 `BAIKAI23333/END-EAC-on-Deespeek-desktop`，先核验再收录 |
| 外观 | 与皮肤包统一按 `appearance` Feature Pack 开放，首个试点为鲸鱼娘系列 |
| EAC | 停止新增 EAC 专属协议、UI、bridge 和事务开发 |
| Legacy | 当前 Mojobox Pack/Lock/归档链路冻结，不删除、不扩展、不作为 MVP 安装输入 |

## 暂不安排

- EAC UI 或 Mojobox 深链接安装；
- 新的 Mojobox 到 Feature Pack 格式桥接；
- Pack 升级迁移、多版本索引和自动升级；
- 完整传递依赖离线闭包；
- 第二个宿主适配器；
- 大规模官方版本迁移或批量升级已有数据。

## 完成定义

首版不以“协议设计完整”作为完成条件，而以真实用户路径为准：

1. 用户能在网站看到首个功能整合包；
2. 官方桌面 Host 市场能读取同一索引；
3. 用户点击一次即可下载、校验并安装；
4. 安装完成后，重启官方桌面端，包内功能可用；
5. 失败不留下错误的半安装记录；
6. 网站归档、索引和 SHA-256 可被第三方复核。
