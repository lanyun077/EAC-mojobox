## 下游需要做什么

将配置中的插件索引完整 URL 切换为上方新入口。接口仍为 `plugins.mojobox.dev/v1`，
来源标识仍为 `dsh-eac.mojobox`，资源 ID、兼容/冲突/限制和下载摘要不变。
相对下载与报告地址继续以新索引 URL 解析，参见[插件来源接口 v1](plugin-source-api-v1.md)。
不要修改旧快照或略过校验来迁移；新源读取失败时保留上次成功目录。

已有 `supply.eac/v1` 草稿仍是独立契约，未因迁移自动变成公开在线批次。
历史 Issue、PR 编号仅属于原仓库；新仓库同号记录不能冒充旧讨论。

## 历史地址和安全边界

当前 README、投稿、网站 GitHub 链接和消费入口使用新地址。
旧文档中的固定来源、日期验收、作者声明、Issue/PR 和原始资源地址保留历史语义，可能失效；
需要引用已恢复文件时，可使用新仓库中的相同提交与路径，不将旧讨论链接替换成无关同号记录。

私有工作区快照、Git 元数据副本、测试缓存与本机恢复路径不进入公开仓库。
恢复后的 main 应继续要求 CI，禁止强推与分支删除，并核对维护者正常合并路径。
分支保护不能阻止拥有仓库删除权限的管理员删除整个仓库；应限制管理员范围并保留异地备份。
