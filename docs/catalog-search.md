# 目录检索

检索在浏览器中读取同一份静态目录完成，不需要服务器、登录或外部搜索服务。
公网是否具备这些能力以实际部署版本为准；官方词表与投稿标注见[官方分类与作者标签](catalog-tags.md)。

## 先选择资源类型

- 插件：独立插件信息卡，可筛选「有核验归档」与「仅来源收录」。
- 功能包：功能和工作流整合包，可按官方用途多选筛选；两种包类型同时存在时另提供类型筛选。
- 皮肤包：同时展示外观归档与 Prompt 资料，可按资源形态与官方主题多选筛选。
- Skill：仍是空分类，不新增收录或搜索内容。

同组官方标签多选取并集，与其他条件取交集。例如选择「二次元」或「游戏主题」，再限定
「Prompt 资料」，只展示属于任一主题的资料。未标注官方分类的资源可按「未分类」筛选。
分类、标签和下载状态不证明运行兼容、安全或无冲突。

## 输入关键词

空格分隔的多个关键词都必须出现，可以出现在不同字段中。忽略英文大小写，统一全角／半角
字符与连续空白。不是拼音搜索、错字纠正或全文语义搜索。

- 插件搜索名称、ID、npm 包名、简介、作者、来源、已知限制与冲突说明。
- 整合包增加搜索详细介绍、所含组件、官方标签 ID、中文名称与少量官方别名。
- 皮肤增加搜索英文名称、加载器 ID、皮肤 ID、已知冲突、备注和资料声明的明暗主题。

例如 `状态栏 轮播` 查找同时提到这两个词的插件；`AIO 会话` 查找名称、介绍或组件中
同时包含这两个词的功能包；在皮肤包中搜索 `XP`，再选择「Prompt 资料」，可缩小结果。
搜索作者仓库名称也可以找到来源关联资源，但仓库所有者不自动被认定为作者。

## 筛选与排序

分类复选项只来自平台维护的官方词表，计数基于当前类型的完整目录，不随关键词或资源形态
改变。没有资源的标签默认隐藏，已选择的合法官方标签可显示 0；无官方标注时显示「未分类」。
不再用组件名回退生成分类，也不从作者标签自动推断官方分类。

现有 `metadata.tags` 和补充 `customTags` 都是作者标签，只在详情页原样展示，不参与分类、
标签文本检索或相关性加权。即使作者标签写了 `anime`，也不能代替官方标注；名称和介绍中
正常出现的文字仍可搜索。外部 Prompt 清单、归档及来源摘要保持不变。

相关性按关键词命中的字段排序：名称／ID／包名优先，其次官方标签、简介／详细介绍，最后作者、
来源与其他说明；名称完整匹配额外优先。同分按名称和 ID 固定排序。「名称」排序忽略匹配
分数，但仍保留全部筛选。没有可靠收录时间和统计服务，本轮不提供最新、热度或下载排行。

插件信息卡暂没有用途分类和标签字段。本轮不猜测用途分类，也不扩展下游 v1 契约；先依靠
中文简介、包名、作者、来源和下载状态检索。后续若需要统一用途词表，应独立评估 Schema
兼容性与作者投递成本。本次官方标注先覆盖整合包与皮肤，不改变插件 v1 接口。

## 分享、返回和清空

关键词和筛选保存在 URL 的 `#` 路由中。复制地址即可分享同样的检索条件；刷新、打开详情
再返回列表会保留条件。更改筛选后支持浏览器后退／前进，输入关键词不会每个字符都新增
一条历史。切换资源类型会清空条件，避免插件下载状态影响皮肤资料。

「清空条件」同时清空关键词与筛选，并恢复相关性排序。链接中的未知或旧作者标签不会变成
官方选项；页面提示不可用分类，没有有效命中时显示空结果，可直接清空。多选参数例如
`#/skins?tag=anime,game&kind=prompt`。排序、资源形态等非法枚举忽略，不作为执行指令或 HTML。

## 实现边界与验证

分类事实源为 `policies/catalog-tags.json` 与 `catalog/website-tags.json`，其余收录事实源不变。
构建会在发布网站目录前校验分类，生成网站专用 `tagGroups` 与 `websiteTags`；不手工编辑
生成目录，不修改作者归档、原始 Prompt、旧 Lock/Evidence、许可与冲突信息，下游插件索引及下载字节保持原样。

提交前运行 `npm test`、根路径与仓库子路径 `npm run build`、`npm run verify:downloads`、
`git diff --check`，并验证桌面／窄屏组合筛选、中文输入、详情返回、刷新和浏览器历史。

2026-10-12 本地验收：160 项测试中 158 项通过，2 项 Windows 符号链接测试跳过；根路径与
`/EAC-mojobox/` 构建及下载复核通过（46 个归档、10 套资料）。Edge 在两种部署路径的
1440、390、320px 下验证了多关键词、全角输入、组合筛选、清空、详情返回、刷新、浏览器
前进／后退与中文输入合成事件，未发现页面异常或横向溢出。
