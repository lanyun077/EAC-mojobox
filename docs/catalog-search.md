# 搜索与筛选

打开 [Mojobox](https://mojobox.cn/)，先选择资源分类：

- **插件**：查找单个扩展，可筛选有下载文件或仅提供来源的条目。
- **功能包**：查找功能增强与工作流组合，按用途标签筛选。
- **外观包**：查找皮肤与主题组合，按主题标签筛选。

## 搜索

输入名称、作者、来源或组件名，空格分隔多个关键词。例如 `AIO 会话` 会查找同时匹配这两个词的整合包。

整合包还可搜索详细介绍、官方标签及其别名；外观包可搜索加载器、皮肤 ID 和冲突说明。
作者自定义标签在详情展示，不参与标签筛选或检索。

## 筛选与排序

官方标签可多选，选中任意一个即可命中，再与关键词和其他条件共同筛选。
「未分类」表示资源没有官方标签。标签说明见[分类与标签](catalog-tags.md)。

可按相关性、收录时间、更新时间或名称排序；功能包与外观包还可按标签相关性、近七日下载和累计下载排序。

下载量来自 GitHub 附件计数，包含重复下载与自动校验；热度使用近七日增量。
统计按日更新，数据不足时会显示提示。

## 分享与返回

复制浏览器地址即可分享搜索条件，例如：

```text
https://mojobox.cn/#/packs?tag=development
https://mojobox.cn/#/skins?tag=anime,game
```

打开详情再返回、刷新页面或使用浏览器前进／后退，均可恢复链接中的条件。
切换分类会清空条件；点击「清空条件」恢复默认排序和完整列表。
